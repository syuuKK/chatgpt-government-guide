ChatGPT 公務實作功能地圖（2026/10/15 更新版）

◎ 使用方式
1. 解壓縮本壓縮檔，保留所有檔案與 pages/ 資料夾。
2. 雙擊 index.html：進入原本的多頁式網站。
3. 點選右上角「簡報模式」，或直接開啟 slides.html：進入 16:9 網頁簡報。
4. 簡報操作：← →／空白鍵翻頁；Home／End 到首尾；F 全螢幕；N 顯示／隱藏講者提示。
5. 功能與方案比較：網站左側「功能與方案比較」，新增十大功能表及 Free／Plus 比較。
6. 所有頁面可離線開啟；外部官方來源連結需要網路。

◎ 編輯維護
- index.html 與 pages/*.html：網站頁面
- style.css、app.js：網站樣式及互動
- slides.html、slides.css、slides.js：簡報模式（相互獨立）
- ChatGPT_功能地圖.md：完整教材與新增對照表

◎ 說明
- 十大功能為課程使用的任務分類，非 OpenAI 官方分類；保留原本六大能力導覽。
- 查核基準：2026/10/15。預計 10/30 前再次確認功能額度與帳號權限。
- 新增內容依網頁簡報的視覺與互動原則實作，未直接呼叫未在本工作環境提供的 frontend-slides 技能。
- 本 ZIP 並未包含獨立單檔合併版，請勿只傳送 index.html；分享時應提供整個資料夾或 ZIP。

◎ 捲動互動更新（2026/10/15）
- Scroll-triggered：功能卡片、重點模組進入畫面時依序淡入，僅播放一次。
- Scroll-linked：網頁頂部閱讀進度條依實際捲動位置連續變化。
- Parallax：首頁背景光暈隨捲動輕微位移，標題和文字不移動。
- Sticky：網站原有頂部導覽保留；方案比較增加 Free／Plus 固定辨識列。
- 簡報模式：保留按鍵換頁與講者提示，換頁增加 320ms 柔和淡入。
- 手機版和偏好減少動態效果的裝置已設定替代效果。
- 不加入強制 Scroll Snap 或水平捲動，避免妨礙大量教材閱讀與簡報操作。
- 程式僅使用原生瀏覽器 API，離線也能正常運作；若瀏覽器不支援動畫，內容仍可閱讀。

2026-10-15 首頁精簡更新：首頁保留六大能力；十大功能總覽移至 pages/capabilities.html，並可由側邊欄直接開啟。詳見 README.md。
