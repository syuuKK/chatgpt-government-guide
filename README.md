# ChatGPT 公務實作功能地圖｜README

> **一分鐘快速上手**｜版本：2026-10-15（11 大功能／CH01–CH06 課綱／方案比較／Irene 教學方向同步）  
> 適用：高雄市政府智慧城市推動種子、資訊處同仁的 ChatGPT 教學展示與課程籌備。

## 先看這 3 件事

1. **開網站**：解壓縮 ZIP 後，雙擊 `index.html`。這是保留六大能力導覽的完整教材網站。
2. **開簡報**：網站右上角選 **「簡報模式」**，或直接開啟 `slides.html`，即可顯示 **12 張 16:9 網頁簡報**。
3. **查功能**：側邊欄選 **「11 大功能總覽」**，可搜尋 11 類功能與公務情境；**「功能與方案比較」** 專門查看 Free／Go／Plus／Business 與 Projects／GPT／Plugins 差異。

**提醒：分享時請傳整個 ZIP／資料夾，不要單獨傳 `index.html`。** 網站需要搭配 CSS、JavaScript 與 `pages/` 才能完整運作。主要內容可離線閱讀；官方來源連結需連網。

## 這一版更新了什麼？

**授課共識（Irene 2026/10/15）：**個人實作，不分組；CH05 語音以講師展示即時口譯、個人助理播報與新聞說明為主，不要求全員同步開麥。CH01 功能總覽與 Projects 入門 60 分鐘，CH02–CH04 情境細節待確認。完整安排請見 `pages/course.html`。


| 部分 | 內容 | 你會看到的效果 |
|---|---|---|
| 網站首頁 | 保留六大能力卡片，移除重複的11 大功能卡片 | 精簡首頁內容，留下完整功能地圖入口 |
| 11 大功能總覽 | 新增獨立 `pages/capabilities.html` | 可搜尋 11 類功能、應用情境並連至能力頁 |
| 功能比較 | Free／Go／Plus／Business 與 Projects／GPT／Plugins 比較 | 避免與11 大功能總覽重複 |
| Scroll-triggered | 卡片進入畫面時依序淡入、微微上浮 | 捲到內容時自然出現，僅播放一次 |
| Scroll-linked | 頁面頂端閱讀進度條 | 滾得越往下，進度越長 |
| Parallax | 首頁背景光暈輕微視差 | 背景有層次，文字不跟著漂移 |
| Sticky | 保留固定導覽，方案比較加入固定辨識列 | 長表格較容易對照 Free／Go／Plus／Business |
| 網頁簡報 | 12 張 16:9 投影片、320ms 柔和換頁 | 可用鍵盤操作與顯示講者提示 |

**刻意未加入** Scroll Snap（強制停在下一屏）與 Horizontal Scroll（垂直捲動帶動橫向位移）：以免干擾教材閱讀及簡報操作。

## 簡報快捷鍵

| 操作 | 按鍵 |
|---|---|
| 下一張／上一張 | `→`、`←`（也支援 `↓`、`↑`） |
| 下一張 | `Space` 或 `Page Down` |
| 上一張 | `Page Up` |
| 第一張／最後一張 | `Home`／`End` |
| 全螢幕 | `F` |
| 顯示／隱藏講者提示 | `N` |

也可以使用畫面上的上一張、下一張按鈕；投影片網址含 `#slide-頁碼`，方便分享指定頁面。

## 之後要改內容，改哪一個檔案？

- **改首頁六大能力卡片與入口** → `index.html`
- **改11 大功能分類及公務應用表** → `pages/capabilities.html`
- **改 Free／Go／Plus／Business 或 Projects／GPT／Plugins 比較** → `pages/compare.html`
- **改網站字體、顏色、捲動動畫** → `style.css` 與 `app.js`
- **改投影片內容** → `slides.html`；改外觀 → `slides.css`
- **改簡報翻頁或動畫** → `slides.js`
- **更新文字教材** → 同步修改兩份 `.md`，避免與網頁不一致

## 注意事項

- **方案差異屬於會變動的資訊**：網站內的方案與額度資料以 **2026-10-15** 為整理基準；**10/30 教材定稿前，應再查一次 OpenAI 官方說明**。不要把現有表格當成永久不變的方案承諾。
- **分類不是官方產品架構**：「六大能力」與「11 大功能類別」是本課程的教學分類，並非 OpenAI 官方分類名稱。
- **動畫不影響閱讀**：支援 `prefers-reduced-motion`；在偏好減少動態效果或部分較舊瀏覽器中，動畫會減弱或略過，內容仍應可讀。
- **開課資料安全**：展示與實作請優先使用公開／模擬資料，避免上傳機密、未公開公務資料及個資；正式行政產出仍需人工查核。
- **技術形式**：原生 HTML／CSS／JavaScript，無需安裝套件或啟動伺服器。此版本依網頁簡報設計原則製作，**並非直接執行未提供於本環境的 `frontend-slides` 技能**。
